Architettura iniziale:

```text
Client
  |
  v
Amazon API Gateway
  |
  v
AWS Lambda (Node.js/TypeScript)
  |
  +----> Amazon DynamoDB
  |
  +----> Amazon SQS / EventBridge
                 |
                 v
          Worker AWS Lambda
                 |
                 +----> Amazon S3
                 +----> servizio/API AI
```
